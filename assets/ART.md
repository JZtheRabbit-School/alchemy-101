# Illustrated assets

Generated with the built-in image generation tool on November 15, 2026. These are local project assets, not remote dependencies. The two user-attached approved basement/book concept images were used as style references. No GitHub publication was performed.

## Prompt set / production briefs

- **basement-illustrated.png:** Match the references' hand-inked, scratchy stippled watercolor and antique illustration aesthetic: cracked moss-green plaster, worn carved walnut shelves, dried herbs, candle, old books, stained tablecloth. Full-bleed 16:9 room. A regular four-column/seven-row EMPTY shelf on the left, large EMPTY transparent glass beaker centrally, four EMPTY element cards on the right, portrait 2:3 closed leather hardcover with crescent/botanical embossing, and metal trashcan. No typography, Elixir sign, counters, items, or baked-in moon symbols. Leave interactive regions empty for HTML overlays.
- **journal-illustrated.png:** One front-facing open antique leather hardcover on uniform dark moss-green background. 4:3 spread; each page 2:3. Projecting rigid boards, layered uneven edges, stitching, worn corners, fine ink hatching, mottled cream parchment and stained edges. Blank writing areas on both pages. No baked-in words, numbers, pictures, tabs or controls. Live illustrations and text are overlaid.
- **items-illustrated.png:** Square transparent sprite atlas, exactly 8x8 cells, one isolated object per cell, no labels or grid. Fine dark ink, stippling, crosshatching, muted watercolor in moss/ochre/rust/burgundy, scientific specimen illustration. Order matches ITEMS in game.js (left to right, top to bottom), with the last cell empty. Includes separate unlit/lit bulbs, empty/full containers, frogs/eggs, magical blood and two distinct Elixir renderings. Cells are clipped in art.js when displayed.

The tool prompts also supplied normalized placement targets for the room. Final live hit areas were aligned to the returned artwork in illustrated.css. The atlas is a first-pass set; individual icons may be refined without changing game rules.
